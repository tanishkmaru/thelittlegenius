# 🧠 The Little Genius – School Website

Welcome to **The Little Genius**, an interactive and fun school website built with HTML, CSS, and JavaScript. It is designed to showcase school features, provide important updates, and let students and parents easily connect with us.

---

---

## 📁 Features

- 🎨 Responsive homepage with animations using GSAP
- 📋 Dropdown menus and navigation bar
- 🧒 Kid-friendly and mobile-friendly design
- 📸 Image slider in the hero section
- 📬 Simple form for student/parent applications (PHP part hosted separately)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GSAP for animations
